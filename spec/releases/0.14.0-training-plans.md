# Code Solver 0.14.0 增量 Spec：每日一题与专项训练

- 状态：已实现
- 日期：2026-08-13
- 基线：0.13.0
- 目标版本：0.14.0
- 范围：`train daily`、`train drill`、训练提交和总结

## 1. 目标

在不降低 solve/review 性能的前提下，为用户生成个性化刷题大纲，记录真实做题过程，最大限度复用已有题解和公开教学资源，并在计划结束时形成可复用总结。

## 2. 命令契约

| 命令 | 默认值 | 结果 |
|---|---|---|
| `train daily [days] [goal]` | 30 天、每天一题 | 每日训练大纲并开始今日题目 |
| `train drill <topic> [count] [goal]` | 7 题、由易到难 | 专项大纲并开始当前题目 |
| `train submit <code-or-description>` | 当前激活计划 | 静态评估并记录进度 |
| `train summary` | 当前激活计划 | 生成计划或专题总结 |

系统记录最近激活计划，`submit` 和 `summary` 默认作用于该计划。

## 3. 复用顺序

1. 创建计划时扫描一次 `code-solver-workspace` 中的题解。
2. 精确题目已存在题解与代码：直接关联，不生成副本。
3. 同题型已有笔记：作为预习或复盘资源引用。
4. 无本地资源：引用公开题目和教学链接。
5. 领取题目时仍缺少题解或代码：在当前任务内复用 0.13.0 fast solve 流程补齐，再写回计划。

公开题目链接只在创建计划时批量验证；每日领取不联网，不得编造未确认链接。

不得递归调用命令或 Skill；内部流程复用不产生额外路由轮次。

## 4. 计划结构

```text
code-solver-workspace/training/
├── active.json
├── daily/<plan-name>/
└── drill/<plan-name>/
    ├── 计划.md
    ├── state.json
    ├── 进度.md
    ├── history.jsonl
    ├── 总结.md
    └── submissions/
```

- `计划.md`：用户可读目标、阶段大纲、题目、链接和引用资源。
- `state.json`：当前题号和最小机器状态。
- `进度.md`：用户可读进度，由脚本刷新。
- `history.jsonl`：只追加提交记录。
- `总结.md`：计划结束时由模型一次生成。
- `submissions/`：保存用户代码，不复制到进度或总结。

运行时脚本按职责拆分：`training.py` 只处理命令，`training_store.py` 只处理索引、路径和状态读写；模型无需加载其源码。

## 5. 今日题目联动 solve

`training.py current` 返回当前题目及复用状态：

- `reuse=true`：展示已有题解、代码和资源。
- `reuse=false`：执行 fast solve；已有单个产物不得覆盖，只补缺失部分。
- 生成完成后调用一次 `training.py link` 关联原始路径。

daily 同一天完成后不提前派发下一题；drill 可继续下一题。

## 6. 提交闭环

- 用户代码：只做一次静态评估，最多两个关键问题，不编译、不运行、不完整重写。
- 文字描述：标记为用户自述，不宣称代码通过。
- 状态：`completed`、`partial`、`blocked`、`skipped`。
- `partial` 安排同类型同难度变式；`blocked` 引用基础笔记并降低下一题难度。
- 只调整未开始项目，不重建完整计划。

## 7. 总结契约

计划结束或用户主动要求时，只读取当前计划进度和已关联题解，生成完成率、用时、掌握点、高频问题、代表题目、笔记链接和下一步建议。

专项总结必须额外包含专题识别信号、通用解题步骤、边界清单和代表题目阶梯。

## 8. 性能与边界

- solve/review 不读取 `training.md` 或训练状态。
- 创建计划只扫描一次已有题解；领取题目只读取当前计划并做一次精确复用检查。
- 不内置或抓取完整题库，只保存公开元数据和链接。
- 不复制算法笔记、题面、官方题解或付费内容。
- 不编译、不运行、不在终端验证用户或生成代码。

## 9. 验收标准

- [x] daily 和 drill 与 solve/review 同级。
- [x] 两种计划均有大纲、进度、笔记引用和总结。
- [x] 精确题目已有归档时直接复用。
- [x] 当前题目缺少归档时复用 solve 补齐并回写链接。
- [x] 用户可提交代码或文字描述并形成进度记录。
- [x] daily 当天最多派发一题。
- [x] solve/review 运行路径不增加训练文件读取。

## 10. 验证边界

仅进行 Frontmatter、结构、路径引用、模式契约和脚本静态检查；遵循产品约束，不执行训练脚本，不编译或运行任何代码。
