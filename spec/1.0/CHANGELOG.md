# Code Solver 1.0 变更说明

- 版本：1.0
- 日期：2026-08-13
- 基线：此前分散的轻量解题、审查与训练 Spec
- 影响范围：仅 Spec 文档结构与版本记录；不修改运行时实现

## 本版本更新了什么

### 新增

- 将每日一题、专项训练、提交记录和训练总结纳入同一份 1.0 完整规格。
- 增加清晰的版本级变更说明，后续可直接查看每个版本新增、变更、移除与兼容性影响。
- 建立 `spec/1.0/SPEC.md` 与 `spec/1.0/CHANGELOG.md` 的双文档结构。

### 变更

- 由原先按零散增量文档描述功能，改为由 1.0 完整规格集中描述当前能力。
- 版本目录由 `spec/versions/` 改为 `spec/1.0/`，一个目录对应一个发布版本。

### 移除

- 移除旧的 0.13.0 及其他历史版本 Spec，不再保留多版本并存的文档结构。

### 兼容性

- 本次仅重构 Spec 文档；不更改 README、命令、Skill、脚本或用户归档。
- 因此不引入运行时命令或数据格式的兼容性变化。

## 后续版本如何记录

新版本采用相同结构，例如 `spec/1.1/`：

| 文件 | 必须记录 |
|---|---|
| `SPEC.md` | 新版本完整行为、数据、边界与验收 |
| `CHANGELOG.md` | 相比上一版本的新增、变更、移除、兼容性与影响范围 |

这样查看任一版本目录即可回答：“这一版具体更新了什么，是否影响已有使用方式。”
