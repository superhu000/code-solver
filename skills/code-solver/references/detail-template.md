# 戳气球 详细题解
> 平台：leetcode｜题号：312｜难度：困难｜题型：dynamic-programming｜语言：java｜链接：https://leetcode.cn/problems/burst-balloons/

## 问题拆解
- 目标：n 个气球排成一行，每个气球有一个分值，戳破气球 i 获得 `nums[i-1]*nums[i]*nums[i+1]` 金币（越界取 1），求最大金币总数
- 输入输出：整数数组 `nums[]`，返回最大金币数
- 数据范围：n ≤ 300，nums[i] ≤ 100
- 复杂度上限：n ≤ 300 → O(n^3) 可接受，O(n!) 不可接受

## 方案对比
| 方案 | 核心思路 | 时间 | 空间 | 时限可行性 | 取舍 |
|---|---|---|---|---|---|
| 暴力递归 | 枚举每次戳哪个气球 | O(n!) | O(n) | 不可行 | 简单但 n>10 即超时 |
| 记忆化递归 | 递归+备忘录去重 | O(n^3) | O(n^2) | 可行 | 本质等同区间 DP |
| 区间 DP | 逆向思维，枚举最后戳的气球 | O(n^3) | O(n^2) | 可行 | 最优，状态定义清晰 |

## 推荐方案
正向思考"先戳哪个"会导致戳破后数组断裂、子问题不独立——戳掉一个气球后，左右两部分合并，相邻关系发生变化，无法形成独立的子问题。

**关键转换：逆向思维。** 不考虑"先戳哪个"，而是考虑"区间 (i,j) 内最后戳的是哪个气球 k"。当 k 是最后被戳的气球时，它的左右邻居一定是区间的边界 i 和 j（因为其他气球已经被戳掉了），所以戳 k 获得的金币是 `nums[i]*nums[k]*nums[j]`。

**状态定义：** `dp[i][j]` = 戳破开区间 (i,j) 内所有气球能获得的最大金币数。开区间意味着 i 和 j 本身不被戳破，它们作为边界存在。

**转移方程：**
```
dp[i][j] = max(dp[i][k] + dp[k][j] + nums[i]*nums[k]*nums[j])  其中 i < k < j
```
对每个 k，左半部分 dp[i][k] 和右半部分 dp[k][j] 是更小的子区间，已经独立求解完毕。

**正确性论证：** 该状态定义无后效性——dp[i][j] 仅依赖更小的子区间 dp[i][k] 和 dp[k][j]，k 是最后戳的气球意味着戳 k 时左右子区间已全部处理完毕，已戳气球不影响后续决策。

**实现细节：** 首尾加虚拟气球值为 1（`arr[0] = arr[n+1] = 1`），从区间长度 2 开始递增枚举，保证计算子区间时边界已就绪。

## 核心代码
```java
int maxCoins(int[] nums) {
    int n = nums.length;
    int[] arr = new int[n + 2];
    arr[0] = arr[n + 1] = 1;
    for (int i = 0; i < n; i++) arr[i + 1] = nums[i];

    int[][] dp = new int[n + 2][n + 2];
    for (int len = 2; len <= n + 1; len++) {        // 枚举区间长度
        for (int i = 0; i + len <= n + 1; i++) {     // 枚举左端点
            int j = i + len;
            for (int k = i + 1; k < j; k++) {        // 枚举最后戳的气球
                dp[i][j] = Math.max(dp[i][j],
                    dp[i][k] + dp[k][j] + arr[i] * arr[k] * arr[j]);
            }
        }
    }
    return dp[0][n + 1];
}
```

**算法步骤**
1. 构造带虚拟边界的数组 arr[0..n+1]，arr[0]=arr[n+1]=1
2. 按区间长度 len 从 2 到 n+1 递增枚举
3. 对每个区间 (i,j)，枚举最后戳的气球 k，更新 dp[i][j]
4. 答案为 dp[0][n+1]

**样例与边界**
- 官方样例：[3,1,5,8] → 167
- 边界用例：n=0 返回 0；n=1 返回 nums[0]；所有值相同如 [2,2,2]

## 复杂度
- 时间：O(n^3)
- 空间：O(n^2)

## 易错点
- 正向思维导致子问题不独立，必须逆向考虑"最后戳哪个"
- 虚拟边界值必须为 1，不是 0
- 区间长度从 2 开始，因为开区间 (i,j) 至少跨 1 个气球时才有意义
- k 的范围是 i<k<j，不含端点
- n=300 时单次金币最大 100×100×100=10^6，累计不超过 300×10^6=3×10^8，int 足够但若值域更大需用 long

## 知识沉淀
- "戳破/消除导致断裂"类问题 → 逆向思维（考虑最后操作的那个元素）→ 区间 DP
- 区间 DP 通用框架：枚举区间长度 → 枚举左端点 → 枚举分割点 k
- 可迁移到矩阵链乘、合并石头等区间合并类题目
