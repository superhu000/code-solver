
# 默认代码审查规范

仅在 review 模式且用户没有提供更高优先级规范时读取本文件。

## 优先级

1. 正确性：算法、边界、空值、溢出、索引和终止条件。
2. 可运行性：入口、输入输出、语言版本和标准库使用。
3. 复杂度：是否满足题目约束，是否存在不必要的高复杂度操作。
4. 可读性：命名、职责、重复代码和关键逻辑说明。
5. 可维护性：耦合、隐藏副作用和不必要的全局状态。

## 语言基线

- Java 使用 Java 17，避免无必要的反射、并发和第三方依赖。
- Python 使用 Python 3，仅依赖标准库。
- C 使用 C17，C++ 使用 C++17，注意内存和越界。
- TypeScript 以 ES2020 为目标，不依赖未声明的运行库。
