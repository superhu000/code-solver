# Pow(x, n) 代码审查
> 平台：leetcode｜题号：50｜语言：java｜模式：review

## 用户代码
```java
class Solution {
    public double myPow(double x, int n) {
        if (n == 0) return 1          // ← 缺少分号
        double result = 1;
        if (n < 0) {
            x = 1 / x;
            n = -n;                   // ← Integer.MIN_VALUE 溢出
        }
        for (int i = 0; i < n; i++) { // ← O(n) 超时
            result *= x;
        }
        return result;
    }
}
```

## 结论
代码**无法编译**（缺少分号），且核心算法**时间复杂度过高**（O(n) 会 TLE），同时存在 **Integer.MIN_VALUE 取反溢出**的边界缺陷。共 3 个问题：阻断 2、重要 1。

## 思路分析
用户思路是"负指数取倒数 + 循环累乘"，方向部分正确（考虑了负指数），但存在两个根本问题：
1. **未使用快速幂**：循环累乘 n 次，时间 `O(n)`。当 `n = 2^31 - 1` 时必然超时，题目要求 `O(log n)`。
2. **忽略 Integer.MIN_VALUE 溢出**：`n = -n` 在 `n = -2147483648` 时溢出（`-(-2^31) = 2^31` 超出 int 上限），回绕为自身，导致死循环或错误结果。

## 语法检查
- **第 3 行**：`return 1` 缺少分号 → **阻断**，编译失败。

```diff
+    }
+
+    private double fastPow(double x, long n) {
+        if (n == 0) return 1;
+        double half = fastPow(x, n / 2);  // 二分拆解：x^n = (x^{n/2})^2
+        if (n % 2 == 0) {
+            return half * half;
+        } else {
+            return half * half * x;       // 奇数次幂需额外乘一次 x
+        }
     }
 }
```

### 问题分析

#### 问题 1：`return 1` 缺少分号
- **优先级**：阻断
- **位置**：第 3 行 `if (n == 0) return 1`
- **证据**：Java 语句必须以 `;` 结尾，当前行末尾缺失，编译器报 `';' expected`。
- **影响**：代码无法编译，完全不可运行。

#### 问题 2：`n = -n` 当 n = Integer.MIN_VALUE 时溢出
- **优先级**：阻断
- **位置**：第 7 行 `n = -n;`
- **证据**：`int` 取值范围 `[-2^31, 2^31-1]`。当 `n = -2147483648` 时，`-n = 2147483648` 超出 `int` 上限，回绕为 `-2147483648`（自身），负数取反后仍为负，后续循环 `i < n` 不执行，返回 `1.0`。
- **影响**：`myPow(2.0, -2147483648)` 期望 `0.0`，实际返回 `1.0`，结果错误。

#### 问题 3：O(n) 循环累乘，未使用快速幂
- **优先级**：重要
- **位置**：第 9–11 行 `for` 循环
- **证据**：循环执行 `|n|` 次，最坏 `2^31` 次迭代。题目约束 `|n| ≤ 2^31`，必然超时。快速幂（二分递归）可将复杂度降至 `O(log n)`。
- **影响**：LeetCode 判定为 Time Limit Exceeded。

## 盲点补全

### 语法与算法盲点
1. **Java 基础语法**：分号缺失属于低级失误，说明编写后未做自检或未使用 IDE 的语法提示。
2. **整型溢出意识**：对 `int` 边界值（`Integer.MIN_VALUE`）的取反陷阱缺乏认知。这是 Java 中负数取反的经典坑，凡涉及"翻转符号"的操作都应警惕。
3. **快速幂算法**：未掌握二分幂思想（`x^n = (x^{n/2})^2`），这是数值计算类问题的核心算法模式。
